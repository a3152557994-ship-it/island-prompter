**灵动提词（IslandPrompter）** 带来三大硬核创新：
1. **顶部前摄 / 灵动岛 60px 黄金锁眼台**：窄视幅自动断句，将正在朗读的高亮行严格锁死在屏幕最顶端中央 `60px` 黄金区，瞳孔紧贴前摄镜头零飘眼；

3. **本地浏览器语音识别模糊跟读**：调用设备原生 `SpeechRecognition` / `webkitSpeechRecognition`，内置同音字模糊编辑距离与前向跳读窗口算法——**停顿即停、跳读自动对齐**，零云端 API 费用，底稿绝不外泄。
